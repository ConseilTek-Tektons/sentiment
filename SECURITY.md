# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Email **support@conseiltek.com** with the repository name, affected version, reproduction details, impact, and a safe contact method. Do not include live credentials, unnecessary personal data, or exploit traffic against systems you do not own.

ConseilTek will acknowledge a complete report, investigate it, coordinate remediation, and publish an advisory when appropriate. Support is focused on the latest release and the `main` branch.

This public reference implementation is not a warranty of fitness for a specific regulatory or production environment. Operators remain responsible for provider configuration, identity policy, data classification, threat modeling, testing, monitoring, backups, and incident response.
